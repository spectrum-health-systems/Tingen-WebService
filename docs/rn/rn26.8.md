## Changed

### Primeval logs

- Primeval logs now start with 'mmssfffffff' instead of 'fffffff', which ensures the chronological order is maintained.
- Primeval logs now start with one of the following prefixes:
  - `PRELOG-TRACE_`  
    Logs that are created prior to the full logging functionality being initialized.  
    These remain in the source code, but are commented-out in production, and have a specific syntax that is unique to each file: `PRELOG-TRACE_%Namespace%-%ClassName%-%MethodName%`
  - `DEBUG`  
    Debug logs, generally for specific debugging purposes.
  - `ERROR`  
    Error logs, generally for specific error handling purposes.

### Session logs

- Trying to get formatting to work across text/markdown/html is proving to be a challenge, and after some thought, I think the best way to handle this is to only have two logging formats for session logs:
  - `text` - Minimal logging, but fast.
  - `markdown` - More verbose logging, but slower (default).

  This way, I can focus on making the `markdown` session logs the best they can be.

### Miscellaneous

- Renamed a few classes/methods to be more descriptive of their purpose, and to follow naming conventions
- Split `Core.Avatar.AvatarDatacs` into `Core.Avatar.AvatarOptionObjects.cs` and `Core.Avatar.AvatarScriptParameter.cs`
- Added `Core.Utility`
- Added `Core.Trove.RunningLog`
- Session folder is now `{AvatarName}/{Date}/{Time}`
- Added error handling in `Utility.AvatarForm.cs`
- Moved `WriteLocal()` and `AppendLocal()` from `Logger.LogWriter.cs` to `Logger.LogUtility.cs`
- Moved `RecreateSystemLogs()` from `Logger.LogMaintenance.cs` to `Logger.LogUtility.cs`
- Renamed `FrameworkMaintenance.cs` to `FrameworkUtility.cs`
- Renamed `SessMaintenance.cs` to `SessUtility.cs`

### Trace logs

- Trace logs now start with `ssfffffff` instead of `ssff-fffff`
