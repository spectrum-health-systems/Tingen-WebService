## What are Tingen Web Service modes?

The Tingen Web Service, and many of it's modules, have various modes they can run in.

## Tingen Web Service modes

Tingen Web Service modes are defined in the web.config <%NEED%> file.

| Mode        | Description                   |
| ----------- | ----------------------------- |
| Enabled     | Full functionality            |
| Disabled    | All functionality is disabled |
| Passthrough | (not implemented)             |

## Dose Change Evaluation OTP module

The Dose Change Evaluation module <%NEED%> modes are defined in the <%NEED%> file.

The Open Incident module <%NEED%> modes are defined in the <%NEED%> file.
