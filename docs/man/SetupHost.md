You'll need a machine that can host the Tingen Web Service, and that machine will need:

* A web server
* The .NET 10.0 SDK
* A specific folder framework
* Access to your Avatar environment

## The Web Server

You'll need to have a web server installed and configured on your host machine.

The recommended web server for the Tingen Web Service is Microsoft IIS.

You can find the installation and configuration instructions [here](dev/madc/InternetInformationServices.md).

## The .NET 10.0 SDK

You'll need to have the .NET 10.0 SDK installed on your host machine.

You can download and install the .NET 10.0 SDK from the official [.NET website](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

## The Tingen Web Service Framework

You'll need to have the [Tingen Web Service framework](../Appendix/Framework.md) set up on your host machine, so the necessary folder structure and dependencies are in place.

## Access to Your Avatar Environment

Avatar will be communicating with your host machine, so you'll need to ensure that your host machine is accessible from the Avatar environment.
