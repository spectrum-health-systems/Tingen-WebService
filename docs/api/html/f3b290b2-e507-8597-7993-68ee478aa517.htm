    Remarks

      About log formats

    Logs can be exported using any of the following formats:

    Plain text (default)
    + Smallest file size (good for raw speed)
    + Can be opened in any text editor
    + Easy to customize
    - Does not support any formatting/styling (totally boring!)
    - Super compact, not the easiest to read

    Markdown
    + Allows for formatting, so logs look nice and are easy to read
    + Super easy to customize
    + The coolest format!
    - Not as widely supported as plain text
    - Probably not the best choice for emailing logs

    HTML
    + Allows for complex formatting
    + Can be opened in any web browser (and most email clients)
    - Largest file size
    - More difficult to customize than plain text or markdown

    In general:
    1. Use plain text it you aren't constantly looking at logs.
    2. Use Markdown if you are constantly looking at logs.
    3. Use HTML if you are emailing logs.
    You can change the log format by in the TingenWebService.config file.
