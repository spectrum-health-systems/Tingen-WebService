    Remarks

      About the Tingen Web Service Session

    The TngnWsvcSession class contains everything needed for the Tingen Web Service to process a request, including:
    • The request (SentScriptParameter)
    • The original data from Avatar (SentOptionObject)
    • The working ([!:AvatarComponent.WorkingOptionObject]) and completed data (CompleteOptionObject) from Avatar
    • Various settings, configurations, and framework information
    • Details about the session
