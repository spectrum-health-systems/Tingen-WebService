    Parameters

    traceLogLimit  String
    The trace log limit, as a string, parsed into TraceLogLimit.
    sessionLogLimit  String
    The session log limit, as a string, parsed into SessionLogLimit.

    Return Value

    LogSettings
    A new LogSettings instance with the parsed limit values.

    Remarks

    Parses traceLogLimit and sessionLogLimit as integers and assigns them to the corresponding properties.

    Example

    C#
    var logSettings = LogSettings.Load(traceLogLimit: "3", sessionLogLimit: "100");
Console.WriteLine(logSettings.TraceLogLimit);   // 3
Console.WriteLine(logSettings.SessionLogLimit); // 100
