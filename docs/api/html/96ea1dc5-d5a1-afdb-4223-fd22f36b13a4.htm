    Remarks

      About Avatar data

    Avatar sends two pieces of data to the Tingen Web Service:
    1. The SentOptionObject
    2. The SentScriptParameter
    If either of these components are missing, the Tingen Web Service cannot function properly. This method checks for the presence of both components and logs an error if either is missing.
