    Remarks

      About blueprints

    Blueprints are essentially templates for output generated by the Tingen Web Service. They are used to format logs,error messages, and other data in a consistent manner.

    When the Tingen Web Service is initialized, these templates are exported to the blueprints\ folder. The external templates can then be modified by the user to customize the log output.

      Restoring blueprints

    To restore a template to its original state:
    1. Delete the template file from the blueprints folder
    2. Restart the Tingen Web Service.
    The original template will be copied back to the blueprints folder.
