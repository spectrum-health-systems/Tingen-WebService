    Remarks

    TngnWsvcSession aggregates everything a single Avatar request needs in one place: the per-session runtime values (Runtime), the resolved framework folder layout (Framework), the active logging configuration (LogSetting), the inbound and working OptionObject data (OptObj), and the script parameter supplied by Avatar (ScriptParameter).

    A session is created by calling Start(OptionObject2015, String, DictionaryString, String), which loads all dependent state, runs the per-session and daily maintenance quick checks, and parses the script parameter before returning the populated session to the caller.
