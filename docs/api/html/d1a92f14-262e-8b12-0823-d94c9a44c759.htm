    Remarks

    FormId performs lookups against the form_id-form_name.trans translation file, which maps Avatar option ids to the form names used throughout Tingen logging and reporting. Centralizing the lookup here keeps the translation file format (one id=name entry per line) hidden from callers and ensures that every read is captured in the per-session trace log.
