    Parameters

    tableName  String  (Optional)
    The name of the translation table being refreshed, or empty to indicate completion.

    Return Value

    String
    A timestamped user message describing the translation refresh status.

    Remarks

    Returns a "start" message when tableName is supplied, or a "complete" message when it is omitted or empty.

    Example

    C#
    // Start message:
Console.WriteLine(msg_Maintenance.RefreshTranslations("FormId"));
// Output: [2026-05-15 10:30:45.12345] Refreshing the FormId translation table...

// Completion message:
Console.WriteLine(msg_Maintenance.RefreshTranslations());
// Output: complete. [2026-05-15 10:30:46.54321]
