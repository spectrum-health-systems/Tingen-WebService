    TingenWebService.Core.Translation Namespace

    Translation helpers for the Tingen Web Service.

    Remarks

    This namespace contains types that read, generate, and manage translation files used to map Avatar identifiers to human-readable values such as form names and user descriptions.

    Classes

    FormIdTranslates Avatar form (option) identifiers into human-readable form names.
    UserIdTranslates Avatar user identifiers into human-readable user descriptions.
