    Remarks

    This entry point performs three steps in order: it builds the session via Load(OptionObject2015, String, DictionaryString, String), runs QuickCheck(Int32, String) and [!:DailyMaintenance.QuickCheck(dynamic)] to enforce log retention and folder integrity, and then parses the script parameter through Parse(Object) so downstream dispatchers can route on the parsed values.
