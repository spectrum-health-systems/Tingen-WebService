    Remarks

      About RedPrints

    RedPrints are templates for output generated by the Tingen Web Service. They are used to format logs, error messages, and other data in a consistent manner.

    Like BluePrints, RedPrints can use plain text, Markdown, or HTML for formatting.
    Unlike BluePrints RedPrints are not exported externally, and are not modifiable by the user.
