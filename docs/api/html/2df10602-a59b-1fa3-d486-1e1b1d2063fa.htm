    Remarks

    OptObj is constructed with the original OptionObject2015 preserved as Original, a Clone assigned to Worker for safe mutation, and Completed initialized to null. The session date and time captured by Load(String, String, String, String, String, String) are reused when resolving framework folder paths so all per-session artifacts share the same timestamp.
