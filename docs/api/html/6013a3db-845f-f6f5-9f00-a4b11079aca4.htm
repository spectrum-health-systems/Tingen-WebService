    Remarks

    TngnWsvcRuntime captures the values that vary from one Tingen Web Service request to the next: the session timestamp, the running version, the operating mode, the active Avatar system and user, and the Netsmar service credentials used to query that system. An instance is built once per session via Load(String, String, String, String, String, String) and then carried on the session object so downstream components can read consistent runtime information without re-evaluating Now or re-parsing inputs.
