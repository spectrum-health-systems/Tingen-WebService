    Remarks

    SessionMaintenance is the counterpart to DailyMaintenance and is invoked once per Tingen Web Service session. It is responsible for lightweight housekeeping that must run on a per-request/per-session cadence rather than once per day, such as enforcing trace log retention limits inside the active session folder.

    This class is a port of Outpost31.Maintenance.SessionMaintenance and is intended to be extended with additional session-scoped maintenance routines as the service evolves.
