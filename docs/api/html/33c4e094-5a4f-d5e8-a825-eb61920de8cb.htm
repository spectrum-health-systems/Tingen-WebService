    The Avatar option id (form id) to look up.
    translationPath  String
    The absolute path to the folder that contains form_id-form_name.trans.
    sessionFolder  String
    The absolute path to the current Tingen Web Service session folder.
    traceLogLimit  Int32
    The maximum number of trace log files retained for the active session.

    Return Value

    String
    The form name that matches optionId, or the literal error code "WSVC2491" when no match is found.

    Remarks

    The translation file is expected to contain one optionId=formName entry per line. Blank lines are skipped, and the first matching entry wins. Trace entries are emitted on entry, on every line scanned, and again when a match is returned so that lookup behavior can be reconstructed from the session trace log.

    Example

    C#
    string formName = FormId.GetFormName(
    optionId:        "1234",
    translationPath: tngnWsvcSession.Framework.TngnWsvcDataFolder.Translation,
    sessionFolder:   tngnWsvcSession.Framework.TngnWsvcDataFolder.Session,
    traceLogLimit:   tngnWsvcSession.LogSetting.TraceLogLimit);
