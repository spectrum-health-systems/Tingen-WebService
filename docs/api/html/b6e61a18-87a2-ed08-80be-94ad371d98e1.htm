    Remarks

    UserId performs lookups against the USERID_UserDescription_Active.translation file, which maps Avatar user names to friendly user descriptions. The file is generated from a source listing by CreateTranslationFile(String, String, Int32, String) during daily maintenance, and is then read at request time by GetUserDescription(String, Int32, String, String).

    Each entry in the translation file uses the caret character (^) as a delimiter between the user name and the user description.
