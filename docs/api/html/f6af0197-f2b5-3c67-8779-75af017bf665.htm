    Remarks

      Types of Script Parameters

    There are two types of Script Parameters:

    Form-specific request
    If a Script Parameter starts with an underscore (`_`), the Tingen Web Service will route the request to a specific form.

    For example, if the Script Parameter is `_OpenIncident-DoSomething`, the Tingen Web Service will route the request to `Module.OpenIncident` for further processing.

    General request
    If a Script Parameter does not start with an underscore (`_`), the Tingen Web Service will treat the Script Parameter as a command to be processed.

    For example, if the Script Parameter is simply `DoSomething`, the Tingen Web Service will route that command to the appropriate code for processing.

      About Translations

    On occasion, Avatar will store information in a format that isn't easily translatable to what the Tingen Web Service expects/needs. In those cases, the Tingen Web Service will use a translation to convert the data into a something it can work with.
    For example, an Avatar FormID may be INCIDENT1, but the Tingen Web Service may expect it to be OpenIncident.
    Translation files are used to convert INCIDENT1 to OpenIncident.
