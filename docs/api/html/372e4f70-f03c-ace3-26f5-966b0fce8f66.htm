    Remarks

    QueryUserId translates an Avatar user id (the value supplied by the Avatar form at runtime) into a Netsmart Staff_Member_ID by issuing a SELECT against the RADplus_users table. The target system (LIVE, UAT, or SBOX) is chosen from the active session's runtime configuration so the same code path can be used in any deployment environment.

    This class also exposes a hook for generating Avatar-to-Tingen translation files, which is used by daily maintenance to keep cached lookups in sync with the source database.
