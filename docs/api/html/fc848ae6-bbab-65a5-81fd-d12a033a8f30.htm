    The numeric error code that should be sent back to the Avatar form.
    errMsg  String
    The human-readable error message describing what failed.

    Remarks

    The error message and the original script parameter are appended to the session's running log via AddToRunningLog(Object, String, String, String) with the "HARD ERROR" category, and then ToReturn(Object, Int32, String) is invoked to deliver the error payload to the Avatar form. This method does not throw; it is intended to be the final step before control returns to Avatar.

    Example

    C#

    errCode:     3,
    errMsg:      "Unable to resolve the requested Avatar user.");
