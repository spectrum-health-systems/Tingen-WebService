    TingenWebService.Core.Logger Namespace

    Logging support for the Tingen Web Service.

    Remarks

    This namespace contains helpers for creating debug, history, session, trace, error, and critical log entries, along with shared logging settings and file-path utilities.

    Classes

    CriticalLogProvides helpers for creating critical error log files.
    DebugLogProvides helpers for writing development debug log files.
    ErrorLogProvides helpers for creating error log files.
    HistoryLogProvides helpers for writing history log entries.
    LogComponentsProvides reusable building blocks used to compose log entries.
    LogEventProvides a unified facade for raising log events of different severities and types.
    LogSettingsRepresents the logging configuration values used by the Tingen Web Service.
    LogUtilityProvides shared file and path helpers used by the logging components.
    SessionLogProvides helpers for building and writing session log files.
    TraceLogProvides helpers for writing trace log files for the current session.
