    Remarks

      About OptionObjects

    An Avatar OptionObject defines the web service contract for use with AvatarNX.

    You can think of it as a box that contains all of the information that is in a form. Avatar sends that box to the Tingen Web Service, and the Tingen Web Service:
    1. Opens the box
    2. Looks through the box for specific information
    3. Uses that information to do something
    4. Potentially modifies the contents
    5. Makes sure everything is in order to be returned to Avatar
    6. Closes the box
    The box is then returned to AvatarNX.

    Additional information
    The Tingen Web Service uses the ScriptLink Standard class library to define the OptionObject and its properties. You can read more about OptionObjects here, and the specific OptionObject2015 implementation here.

      Types of OptionObjects

    The Tingen Web Service defines three types of OptionObjects:

    The SentOptObj
    This is the OptionObject that Avatar sends to the Tingen Web Service. It contains all of the information that the Tingen Web Service needs to process a request.
    The SentOptObj is never modified by the Tingen Web Service; it is the One Source Of Truth.

    The WorkerOptObj
    This is the OptionObject that is used to process a request, and may potentially be modified by the Tingen Web Service.

    The CompleteOptObj
    This is the OptionObject that is returned to Avatar after potentially being modified by the Tingen Web Service.
