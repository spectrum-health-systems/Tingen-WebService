    Parameters

    avatarSystem  String
    The name of the Avatar system, used as a subfolder under serverDataPath.
    avatarUserId  String
    The Avatar user ID, used to scope the session path to a specific user.
    serverDataPath  String
    The root server data path from which all folder paths are derived.
    sessionDate  String
    The date of the session, used as a subfolder in the session path.
    sessionStartTime  String
    The start time of the session, used as the innermost subfolder in the session path.

    Return Value

    TngnWsvcDataFolders
    A new TngnWsvcDataFolders instance with all folder paths populated.

    Remarks

    All paths are constructed as absolute paths rooted at serverDataPath and the supplied avatarSystem.

    Example

    C#
    var folders = TngnWsvcDataFolders.Load(
    avatarSystem:     "LIVE",
    avatarUserId:     "jsmith",
    serverDataPath:   @"C:\Tingen_Data",
    sessionDate:      "2026-05-15",
    sessionStartTime: "103045");

Console.WriteLine(folders.DataRoot);
// Output: C:\Tingen_Data\LIVE

Console.WriteLine(folders.AppDataRoot);
// Output: C:\Tingen_Data\LIVE\AppData

Console.WriteLine(folders.Session);
// Output: C:\Tingen_Data\LIVE\Session\2026-05-15\jsmith\103045
