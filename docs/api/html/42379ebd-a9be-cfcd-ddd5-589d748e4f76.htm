    Remarks

      About the Tingen Web Service Session

    This class contains everything needed for the Tingen Web Service to process a request, including:
    • The request (sentScriptParam)
    • The original data from Avatar (AvatarData)
    • The working (WorkerOptObj) and completed data (CompleteOptObj) from Avatar
    • Various settings, configurations, and framework information
    • Details about the session
