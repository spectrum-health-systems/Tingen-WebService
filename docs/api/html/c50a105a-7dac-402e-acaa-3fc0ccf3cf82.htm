    TingenWebService.Core.Query Namespace

    Database query helpers for the Tingen Web Service.

    Remarks

    This namespace contains routines that resolve Avatar user identities against the supported Netsmart systems and generate translation files used by other parts of the service.

    Classes

    QueryUserIdResolves Avatar user identifiers by querying the appropriate Netsmart system database.
