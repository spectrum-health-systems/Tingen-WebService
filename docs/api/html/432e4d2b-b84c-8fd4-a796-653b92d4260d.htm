    Parameters

    version  String
    The Tingen Web Service version string for this session.
    mode  String
    The operating mode for the session; the value is stored in lowercase.
    avatarSystem  String
    The target Avatar system identifier (for example "LIVE", "UAT", or "SBOX").
    avatarUserId  String
    The Avatar user id for the session; the value is stored in lowercase.
    ntstWsvcUserName  String
    The Netsmart service account user name used for Avatar queries.
    ntstWsvcUserPass  String
    The Netsmart service account password used for Avatar queries.

    Return Value

    TngnWsvcRuntime
    A fully populated TngnWsvcRuntime with the session date and time captured from Now.

    Remarks

    SessionDate and SessionTime are sampled at construction so every component that inspects the runtime sees the same timestamp for the duration of the session. RunningLog is initialized to an empty string and is intended to be appended to as the session progresses.

    Example

    C#
    var runtime = TngnWsvcRuntime.Load(
    version:          "1.0.0",
    mode:             "LIVE",
    avatarSystem:     "LIVE",
    avatarUserId:     "JDOE",
    ntstWsvcUserName: "tngn_svc",
    ntstWsvcUserPass: "********");
