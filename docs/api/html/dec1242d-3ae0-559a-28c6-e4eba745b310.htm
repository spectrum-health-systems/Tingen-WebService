    Remarks

    This method is required by Avatar.

      What might happen

    One of three things will occur when this method is called:
    • If a critical failure is detected, an empty OptionObject2015 is returned immediately.
    • If the mode is enabled or passthrough, a TngnWsvcSession is started and the completed option object is returned.
    • In all other cases, an empty OptionObject2015 is returned as a fallback.
