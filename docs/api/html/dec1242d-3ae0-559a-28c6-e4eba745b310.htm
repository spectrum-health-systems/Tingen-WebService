    Remarks

      The Magic of RunScript()

    The RunScript() method:
    • 1 - Verifies that Avatar actually sent data
    • 2 - Hands things off to StartApp()
    The StartApp() method will then do it's thing, after which we'll return to this method, and...
    • 3 - Write the session log
    • 4 - Return a (potentially) modified OptionObject to Avatar

    The reason that all of this logic is here is because this way the CompletedOptionObject is returned to Avatar from a single location, regardless of whether the request was successful or not.

      Why "sentOptObj" and "sentScriptParam"?

    For some unexplainable - at least to me - the OptionObject and Script Parameter sent from Avatar must be named "sentOptObj" and "sentScriptParam", otherwise you'll get an error when Avatar tries to process the response. This is only the case for the RunScript() method.

    This method is required by Avatar.
