    Remarks

      About Avatar OptionObjects

    An Avatar OptionObject2015 defines the XML contract required for use with myAvatar ScriptLink.

    The Tingen Web Services uses three different OptionObjects:
    • Original: The original OptionObject that is passed from myAvatar, and is never modified
    • Worker: The working copy of the OptionObject that is used for processing, and may be modified as needed
    • Completed: The completed OptionObject that is returned to myAvatar
    You can read more about OptionObjects here.
