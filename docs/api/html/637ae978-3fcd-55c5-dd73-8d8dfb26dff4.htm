    Remarks

      About Avatar data

    Avatar sends two pieces of data to the Tingen Web Service:
    1. The OptionObject (which you may see referred to as a "OptionObject2015")
    2. The Script Parameter
    Both of these components are required; if either of these components are missing, the Tingen Web Service cannot function properly.


    This class focuses on OptionObjects.

      About OptionObjects

    An Avatar OptionObject defines the web service contract for use with Avatar.

    You can think of it as a box that contains all of the information that is in a form. Avatar sends that box to the Tingen Web Service, and the Tingen Web Service:
    1. Opens the box
    2. Looks through the box for specific information
    3. Uses that information to do something
    4. Potentially modifies the contents
    5. Makes sure everything is in order to be returned to Avatar
    6. Closes the box
    The box is then returned to Avatar.

    Additional information
    The Tingen Web Service uses the ScriptLink Standard class library to define the OptionObject and its properties.

    You can read more about OptionObjects here, and the specific OptionObject2015 implementation here.
