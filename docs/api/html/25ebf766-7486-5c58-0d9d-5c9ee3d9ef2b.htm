    TngnWsvcWwwFoldersLoad Method

    Creates a fully populated TngnWsvcWwwFolders instance for the given Avatar system.

    Parameters

    avatarSystem  String
    The name of the Avatar system subdirectory under the WWW root.
    serverWwwPath  String
    The absolute path to the server's WWW root directory.

    Return Value

    TngnWsvcWwwFolders
    A new TngnWsvcWwwFolders instance with all folder paths populated.

    Remarks

    All paths are constructed by combining serverWwwPath and avatarSystem.

    Example

    C#
    var wwwFolders = TngnWsvcWwwFolders.Load("LIVE", @"C:\inetpub\wwwroot");

Console.WriteLine(wwwFolders.WwwRoot);
// Output: C:\inetpub\wwwroot\LIVE

Console.WriteLine(wwwFolders.AppDataRoot);
// Output: C:\inetpub\wwwroot\LIVE\bin\AppData

Console.WriteLine(wwwFolders.Blueprint);
// Output: C:\inetpub\wwwroot\LIVE\bin\AppData\Blueprint
