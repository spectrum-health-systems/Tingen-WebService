    TingenWebService.Trove Namespace

    A collection of resources used by the Tingen Web Service.

    Remarks

    The Trove is a collection templates, preset values, and other resources used by the Tingen Web Service to format data in a consistent manner.
    The Trove contains:
    • [Blueprint] – User-modifiable templates (e.g., log files, error messages)
    • [Catalog] – Preset components (e.g, list of required directories)
    • [Epistle] – Preset messages (e.g., welcome messages, notifications)
    • [Epistle] - Preset messages (e.g., welcome messages, notifications)
