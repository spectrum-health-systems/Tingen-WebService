## Primeval log naming convention

Primeval logs now start with one of the following prefixes:

- `PRELOG-TRACE_`  
    Logs that are created prior to the full logging functionality being initialized.  
    These remain in the source code, but are commented-out in production, and have a specific syntax that is unique to each file: `PRELOG-TRACE_%Namespace%-%ClassName%-%MethodName%`

- `DEBUG`  
    Debug logs, generally for specific debugging purposes.

- `ERROR`  
    Error logs, generally for specific error handling purposes.

### Session logs

Trying to get formatting to work across text/markdown/html is proving to be a challenge, and after some
thought, I think the best way to handle this is to only have two logging formats for session logs:

- `text`  
  Minimal logging, but fast.

- `markdown` (default)  
  More verbose logging, but slower.

This way, I can focus on making the `markdown` session logs the best they can be.

### Trace logs

- Trace logs now start with `ssfffffff` instead of `ssff-fffff`
