***

This release focuses on documentation, with the creation of several comprehensive manuals and references, as well as the creation/update of source code XML documentation.

Additionally, a collection of documentation from the (now defunct) MyAvatar Development Community has been archived and made available.

## NEW

* The **Tingen Web Service Manual**  
Details deploying, configuring, and using the Tingen Web Service.

* The **Tingen Web Service Development Manual**  
Contains guidelines for developing the Tingen Web Service.

* The **Tingen Web Service API Reference**  
A comprehensive reference for the Tingen Web Service API.

* The **Tingen Web Service Glossary**  
Has been created to define terms related to the Tingen Web Service. It includes definitions for technical terms, acronyms, and other terminology used in the Tingen Web Service documentation.

* **The MyAvatar Development Community documentation archives**  
A collection of documentation from the (now defunct) MyAvatar Development Community.

***

## UPDATED

* **Project XML documentation**  
XML documentation for all source code has been created/updated. This documentation provides detailed information about the classes, methods, properties, and other elements of the Tingen Web Service source code. It is intended to assist developers in understanding and working with the Tingen Web Service codebase.
