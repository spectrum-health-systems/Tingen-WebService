* Moved the project path to `ThirdParty\Sandcastle Help File Builder`

### ScriptLink Standard

Moved ScriptLink Standard to `ThirdParty\ScriptLink Standard` to keep all third-party dependencies in one place, and makes more sense now that the web service is a single project.
