  <h1>Development requirements</h1>

</div>

The following are the requirements for developing the Tingen Web Service:

* [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)  
  * .NET Framework 4.8.1 SDK
  * .NET Framework 4.8.1 targeting pack
  * .NET Framework project and item templates
* [ScriptLink Standard](https://rcskids.github.io/ScriptLinkStandard/) - A class library for creating SOAP web services for AvatarNX™
* [Sandcastle Help File Builder](https://github.com/EWSoftware/SHFB) - Documentation generation

You will also need to install the following Visual Studio workloads and components:

* ASP.NET and web development
* Azure development
* .NET desktop development
